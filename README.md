# C Calculator

A simple terminal-based calculator written in C.

## Description

C Calculator is a small terminal application that performs basic arithmetic operations through a simple interactive menu.

The application includes the following options:

* Add
* Subtract
* Multiply
* Divide
* Quit

Users can enter two numbers, choose an operation, and instantly view the result. The program also prevents division by zero and handles invalid menu selections.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division by zero protection
* Menu-driven interface
* Simple and clean code
* Easy to understand for beginners

## Technologies Used

* C
* GCC Compiler
* Standard C Library (`stdio.h`)

## Files Required

To run the project, you only need:

```text
calculator.exe
```
